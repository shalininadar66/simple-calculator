Simple Calculator Web App

This project is a simple calculator web application built using Python and Streamlit.
It allows users to perform basic arithmetic operations (addition, subtraction, multiplication, and division) through a browser-based interface.

The project is a conversion of a command-line calculator into a web application, demonstrating how terminal-based Python programs can be adapted into interactive web apps.

Features

Addition, subtraction, multiplication, and division

User-friendly browser interface

Error handling for invalid operations (such as division by zero)

Instant result display

Technologies Used

Python

Streamlit

How It Works
The user enters two numbers, selects an arithmetic operator, and clicks the "Calculate" button.
The application processes the input and displays the result instantly on the webpage.

How to Run the Project

Install the required dependencies

Navigate to the project folder

Run the Streamlit application

Example command:
streamlit run calculator_app.py

Project Structure

calculator_app.py → main Streamlit web app file

requirements.txt → list of dependencies

Purpose of the Project
This project was created to demonstrate the transition from a command-line interface (CLI) Python program to a browser-based web application using Streamlit.
